# AI Coding 自主度分级

> 一句话定义：给"AI 替开发者干多少活"定级的框架谱系——用统一的等级语言让团队说清"我们现在在哪一级、要去哪一级"，从而把 AI Coding 变成**可治理、可衡量**的对象。现有两个同构框架：去哪儿 L0–L5（自动驾驶类比）与 Dan Shapiro 五级（车辆驾驶类比）。

## 核心观点

### 两个框架对照

| 等级 | 去哪儿 L0–L5（2026-06） | Dan Shapiro 五级（2026-01，Cole Medin 引用） |
| --- | --- | --- |
| 0 | L0 全手动，不用 AI | 手动挡——AI 只做"火辣补全"（spicy autocomplete） |
| 1 | L1 代码补全与辅助 | 结对程序员——AI 自主生成一些样板代码 |
| 2 | L2 按注释/文档生成模块，人监控组装 | （同上，L1/L2 合述） |
| 3 | L3 有条件自动化：人给需求+规范+示例，AI 生成可运行代码并自测，阻塞求助 | 人当经理——agent 写大部分代码，人深度在环做规划与最终验证 |
| 4 | L4 高度自动化：AI 承担编码/测试/集成/交付，人管目标/架构/审查 | 连方向盘都没有——只剩控制台给高层方向（PRD） |
| 5 | L5 完全自动化：需求→上线全 AI，人仅异常介入 | （同上，L4/L5 合述；第五级=工厂连 issue 都自己写） |

- 两框架级数与切分不同（6 档 vs 5 档），但谱系同构：**人从执行者 → 结对者 → 经理 → 只定方向**。
- 共同的方法论功能：① 统一语言（"我们用 AI 写代码"人人理解不同，分级后可对齐）② 治理依据（不同等级配不同人工审查强度）③ 衡量标尺（跨级=个人效率→组织能力的非线性跃迁）。

### L3 是分水岭（跨源共识）⭐

- [[Cole Medin 黑灯工厂实验]]：**"第三级才是多数人该待的地方"**；他自己的黑灯工厂诚实标定在第四级而非第五级（人仍提 issue + 发版）。
- [[去哪儿网 AI Coding 研发平台实践]]：2026 H1 目标即 **L3 任务占比 30%+**（1–2pd 需求已达 80%+）；L3 判定有 T/M/C 数据支撑（时长/消息数/输入字符）。
- 解读：L3（有条件自动化 / 人当经理）是**收益与风险的可 defended 平衡点**——AI 端到端干活，人在关键节点审查；再往上对 harness 与验证体系的要求陡增。

### 等级越高，越依赖 harness

- L4+ 的两个独立实证都把重心放在约束系统而非模型：黑灯工厂（治理文件宪法 + 盲测 + 禁区 + 蓝绿部署）与去哪儿天弦（Harness 四把锁 + 自修复闭环 + 质量门禁）。→ 见 [[Harness Engineering]]。
- 诚实定级本身就是纪律：Cole "白纸黑字写在 README"；去哪儿用 Git Blame 出码率与 T/M/C 防自欺——**定级必须可观测**，否则分级沦为口号。→ 见 [[Agent 测评 Eval]]。

## 证据 / 来源

- [[去哪儿网 AI Coding 研发平台实践]]（2026-06）— L0–L5 六级定义 + 组织级目标（L3 占比 30%+）+ L1–L3 可观测化（T/M/C + AI 改动占比）。
- [[Cole Medin 黑灯工厂实验]]（2026-08）— Dan Shapiro《The Five Levels: from Spicy Autocomplete to the Dark Factory》（2026-01）五级 + Cole 自定第四级 + "第三级是多数人该待的地方"。

## 与本 wiki 其他概念的关系

- [[Harness Engineering]]：等级跃迁的前提——L4+ 全部以 harness 前置为条件（黑灯工厂"可靠性靠提前搭建，不靠运气"）。
- [[HITL 与 AFK]]：等级 ≈ HITL 节点的密度谱——L0/L1 全 HITL，L3 关键节点 HITL，L4 只剩"两盏灯"（入口 issue、出口发版），L5 理论上无灯。
- [[Agent 测评 Eval]]：等级判定需要度量体系支撑（T/M/C / pass^k），否则定级不可信。
- [[LLM Wiki]]：本 wiki 语境下，"分级"也提示知识库维护的人机分工演进——当前 ingest 是 L3 形态（人在环过要点），批量自动化是更高等级。

## ⚠️ 矛盾 / 未解问题

- 两框架**不同源且级数不同**（去哪儿 6 档借鉴自动驾驶；Shapiro 5 档车辆类比），L4/L5 边界语义有出入（去哪儿 L4 人仍管架构审查；Shapiro L4 只剩 PRD）——引用时必须注明用的哪个框架。
- 等级判定方法尚无行业标准：去哪儿用 T/M/C + AI 改动占比，Shapiro 框架无配套度量——跨组织等级数字不可直接横比。
- 待观察：该分级是否会像自动驾驶 SAE 分级一样收敛为行业标准命名。
