# 超级奶爸老谭

> 一句话定义：微信公众号作者（署名「超级奶爸老谭！」，文首带「共渡时艰」），Java 出身老程序员，中文圈 AI 编程 skills 的系统性教学者——2026-08 完成「mattpocock/skills 完全指南」系列（12 篇），2026-08-21～09-23 连载第二套「Superpowers · 幸福账本」系列（已完结，24+1 篇全收录），**先后把"路线之争"的两条路线各系统教了一遍**。风格是「开场故事 → 机制拆解 → 何时不要用 → 快速回顾」。

## 概述

与 [[运维有术]]（源码级解读）不同，老谭的两套系列走的是**教学路线**：用可跑的虚构项目把每个 skill 讲成「坑 → 解药」的故事。固定结构：开场故事 → 机制拆解 →「何时不要用」边界 →「快速回顾」。日更 08:05。两套系列各配一个贯穿项目：

- **系列一（mattpocock skills，已完结 12 篇）**：EShop（Java Spring Boot 3 + MyBatis-Plus + MySQL 电商系统）。
- **系列二（[[Superpowers]]，已完结）**：幸福账本（家庭记账：Java 21 + Spring Boot 3 + H2 后端 + Vue 3 + Element Plus 前端，前后端完整项目）。角色阵容：艳姐（需求方/验收人）、乐乐（零花钱子账本）、老王（邻居/小白提问者）。
