# 去哪儿网

> 一句话定义：大型 OTA（在线旅游）公司，2025 年起全面落地 AI Coding，是目前公开样本中把 AI Coding 做成**组织级平台能力**最完整的大厂实践之一（基础架构负责人/技术总监李佳奇团队，2026-06 分享）。

## 概述

去哪儿 2025 年激进决定"全员 AI Coding"：应用层从 prompt 级到 Agentic AI 全铺开（数万 PD 级业务提效、近亿级业务价值），模型层接入 DeepSeek/GPT/Gemini/Claude/GLM/Qwen 等。基础架构团队的打法是**先回答"度量"**——在数据底座上建 AI Coding 数据体系，再以自动化平台承接编排，以企业定制框架承接复杂需求，以 Skills 治理把个人经验变组织资产。

## 关键属性 / 事实

- 成果（2026-06 分享自述口径）：**100%** 研发人员覆盖（FE/BE/QA/部分 PM）、全司出码率 **75%+**、L3 自动化占比 **30%+**（1-2pd 需求 80%+）、天弦自动化任务 **3000+**、测试通过率 **90%+**、150 人黑客松完赛出码率 **90%+**
- 核心人物：李佳奇（基础架构负责人 / 技术总监，分享者）
- 核心理念：AI R&D Metrics = Volume × Maturity；**Harness 决定 AI Coding 上限**；AI Coding 的上限取决于研发系统是否为 AI 重新设计
- ⚠️ 以上数字均为大会分享自述，无第三方复核（见 [[去哪儿网 AI Coding 研发平台实践]] 矛盾区）

## 内部产品（AI Coding 三件套）

### QunarDevCenter — 数据采集与 CLI 代理
多端 session 采集（Claude Code / Codex / Cursor / Copilot / OpenCode）+ 公司大模型统一接入代理；本地白名单过滤上报（仅公司 GitLab 仓库）；三张核心表支撑出码率与 T/M/C 分析。

### 天弦（QDO，Qunar Dev Orchestrator）— 研发自动化编排平台
多 Agent（Claude Code/Codex）多 Skills 全链路编排，**自修复闭环**（编译/部署/测试失败→AI 查日志→修复→重试）；场景含一句话需求、异常修复、线上诊断、JDK 自动升级（OpenRewrite + Agent：211 应用、编译通过率 93%）。

### Qsuperpowers — 企业定制版 Superpowers
基于社区版 [[Superpowers]] 四阶段流程 + 企业四大集成（飞书文档 / AST / CI-CD / 灰霸测试）；复杂需求 3pd→1pd、提效 66%、无 bug 上线。详见 [[Superpowers]] 页"企业级定制印证"。

### Skills 体系与治理
50 Skills / 4 Domain（通用研发 / 业务域 / 企业工具链 / Agent 角色）；私有仓验证→PR→基础研发审核→Skills Gateway 统一分发执行观测 + 种子上下文注入 + Skill 市场。

## 演变 / 时间线

- **2025**：全面落地 AI Coding；H1 完成研发全流程数字化埋点（任务/测试/发布/监控链路串联）
- **2026**：在其上建成 AI Coding 数据体系（QunarDevCenter）；H1 目标 L3 占比 30%+；天弦任务规模化 3000+；150 人黑客松完成组织级极限压测
- 下一步：深化 L3 场景、Skills 资产沉淀、质量门禁强化、AI Native 能力升级
