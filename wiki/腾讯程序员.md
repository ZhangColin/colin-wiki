# 腾讯程序员

> 一句话定义：微信公众号「腾讯程序员 / 腾讯技术工程」，本文作者 atreusliu；发布面向团队的 [[Harness Engineering]] 落地规范（基于 CodeBuddy/Knot 生态），代表大厂团队级 AI Coding 治理视角。

## 概述

在本 wiki 语境下，「腾讯程序员」的价值是提供了 **团队级（而非个人级）的 Harness 落地样本**：把 OpenAI 的 Harness Engineering 理念（6 大支柱）落到具体工具链（CodeBuddy 插件、Knot 平台、team-harness 仓库、harness-audit 审计 Skill），并给出 3 阶段实施路线图与 SOP/反模式/红线清单。

## 关键属性 / 事实

- **品牌**：公众号「腾讯程序员 / 腾讯技术工程」；本文署名 atreusliu。
- **生态**：腾讯 CodeBuddy（IDE 插件 + CLI）+ Knot 平台（知识库/MCP/Rules/Skills/智能体管理）+ 司内 CLI（Claude Code Internal / Gemini CLI Internal / Codex CLI Internal）。
- **核心主张**："让各类工具适配规范，而不是靠个人去适配各类工具"；"流水的工具，铁打的规范"。
- **方法论贡献**：harness-audit Skill——"Skill 就是规范的可执行版本"（7 维度打分，把规范固化为可执行的合规性审计）。
