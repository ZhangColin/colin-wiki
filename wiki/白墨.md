# 白墨

> 一句话定义：微信公众号「白哥Agent落地局」作者，本 wiki 收录其 6.6 万字长文 [[企业 Agent 落地十二大工程框架]]（2026-07-30，上篇）——首次提出「企业 Agent 落地十二大工程框架」（六纵六横），代表**企业级 Agent 落地的方法论综合视角**。

## 概述

在本 wiki 语境下，白墨的价值是提供了 **迄今最全的企业 Agent 工程清单**：

- **十二大工程**：纵向主链（Prompt → Context → Skill → Agent → Harness → Loop）+ 横切支撑（Data / Ontology / Process / Evaluation / Safety-Governance / Product-UX）。
- **独创贡献**：① 每项工程与其他十一项的协同关系网；② Process / Agent / Harness 三者边界划分（业务运转/任务完成/系统运行）；③ 企业 Agent 落地成熟度模型 L1-L5（下篇发布）；④ Action 语义模型（本体工程从「描述世界」走向「支撑安全行动」的关键）。
- **定位差异**：白墨把 Harness 定位为十二工程之一（运行控制面），与 OpenAI「Harness = Agent - Model」的宽定义不同——见 [[Harness Engineering]] 定义谱系。
