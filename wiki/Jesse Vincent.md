# Jesse Vincent

> 一句话定义：开源老兵，GitHub ID `obra`，[[Superpowers]] 的创建者；知名开源项目 RT（Request Tracker）作者、多个热门 npm 包贡献者。

## 概述

Jesse Vincent 是 [[Superpowers]]（`github.com/obra/superpowers`）的作者，把"高质量软件工程工作流"编码成 Claude Code 可执行 skill。在本 wiki 多个源中，他关注的重点是工程规范和代码质量（与 [[Garry Tan]] 关注产品决策/全生命周期形成对照）。他在 Heavybit 播客表态"way more expensive to make broken software"，更看重正确性而非单纯压价。

## 关键属性 / 事实

- **GitHub**：`obra`；仓库 `github.com/obra/superpowers`。
- **代表作**：RT（Request Tracker）；多个热门 npm 包。
- **博客**：blog.fsck.com（Superpowers 首发博文 blog.fsck.com/2025/10/09/superpowers/）。
- **Superpowers 关键设计理念**："作者和审查者绝不在同一个上下文里互评"——写完代码不能立刻自我审查。
- **纪律严格性**：Superpowers 源自一个 **94% PR 拒绝率** 的开源项目（据其 CLAUDE.md），极其严格。
