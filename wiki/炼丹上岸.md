# 炼丹上岸

> 一句话定义：微信公众号「炼丹上岸」，2026-08-30 发布 [[从 Chat UI 到 Agent UI]]——把 Agent 产品交互设计从「更漂亮的聊天框」升级为围绕执行过程（Run）的界面体系的系统性方法论。

## 概述

面向 Agent 产品团队的前端/产品设计方法论输出者。主张：Agent UI 的设计对象是八类对象（Conversation/Message/Run/Step/Tool Call/Approval/Artifact/Event），核心是 Message Part 数据模型、Run 状态机、Snapshot+Event Log+Live Stream 恢复架构与统一事件 Reducer；对 Generative UI 持「企业系统受控组件注册表，不执行模型生成 HTML」的审慎立场。

## 关键属性 / 事实

- **平台**：微信公众号（mp.weixin.qq.com）。
- **代表作品**：[[从 Chat UI 到 Agent UI]]（2026-08-30）。
- **关键主张**：① Agent UI 的第一原则是把内部执行状态转换为可理解、可判断、可操作的界面状态；② HITL 是真暂停，确认后从暂停位置继续而非重跑；③ 取消页面订阅 ≠ 取消 Agent 执行；④ 推荐五层前端架构 + 四阶段演进路线（Chat UI → Tool-aware → Agent Runtime UI → Agentic Application UI）。
