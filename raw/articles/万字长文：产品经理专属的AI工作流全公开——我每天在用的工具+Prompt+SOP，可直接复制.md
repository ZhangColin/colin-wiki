## 为什么你用AI还是效率低？因为缺少"工作流思维"

先说一个很多人不知道的真相：

**AI不是"临时帮手"，而是"工作伙伴"。**

大部分人用AI的方式是：

- • 遇到问题→打开ChatGPT→问一个问题→用一下结果→关掉

这就像你雇了一个实习生，但只让他帮你倒水、复印文件——完全没发挥他的价值。

**真正高效的用法是：把AI嵌入到每个工作环节，形成可复用的工作流。**

什么是工作流？

> “
> 
> **工作流 = 标准化流程 + AI自动化 + 可复用模板**

举个例子：

**没有工作流的需求分析：**

1. 1\. 手动整理用户访谈记录（1天）
2. 2\. 凭经验提炼需求（半天）
3. 3\. 拍脑袋排优先级（半天）

**有工作流的需求分析：**

1. 1\. 用AI自动分析访谈记录，提取关键信息（10分钟）
2. 2\. 用AI按KANO模型分类需求（10分钟）
3. 3\. 用AI结合业务数据智能排序（10分钟）

**差距在哪里？**

不是AI更聪明，而是你有一套标准化的流程，AI可以自动化执行每个步骤。

**记住一句话：AI不会替代产品经理，但会用AI工作流的产品经理会替代不会用的。**

## 工作流1：需求分析——从用户访谈到需求优先级排序

### 场景

你刚做完10个用户访谈，有一大堆录音和笔记，现在要提炼出需求列表并排优先级。

以前要2天，现在用AI工作流只要2小时。

### 工具推荐

- • **访谈分析** ：Claude / ChatGPT（长文本理解能力强）
- • **需求分类** ：Notion AI / 飞书AI（可以直接在文档里用）
- • **优先级排序** ：自定义GPTs（可以固化你的业务逻辑）

### SOP流程

**第1步：AI快速提取访谈关键信息（10分钟）**

把访谈记录（录音转文字或笔记）喂给AI，让它提取结构化信息。

**Prompt模板：**

```
我做了一场用户访谈，以下是访谈记录：

【粘贴访谈记录】

请帮我提取以下信息，用结构化的方式呈现：

1. 用户基本信息（角色、使用场景、使用频率）
2. 核心痛点（按痛点强度排序，用1-5分标注）
3. 期望功能（用户明确提到想要的功能）
4. 未明确表达但隐含的需求（从行为中推断）
5. 关键引语（可以作为需求说明的原话）

输出格式：
## 用户画像
- 角色：
- 场景：
- 频率：

## 痛点列表
1. 【痛点1】（痛点强度：X/5）
   - 原话："..."
   - 影响：...

## 需求列表
1. 【需求1】（明确需求/隐含需求）
   - 来源：...
   - 价值：...
```

**真实案例输出：**

```
## 用户画像
- 角色：B端产品运营，3年经验
- 场景：每周需要制作数据报告给老板
- 频率：每周1次，每次耗时3小时

## 痛点列表
1. 数据散落在多个平台，需要手动复制粘贴（痛点强度：5/5）
   - 原话："我每周光是从5个平台导数据就要花1小时"
   - 影响：重复劳动，效率低

2. 不知道数据异常的原因，只能描述现象（痛点强度：4/5）
   - 原话："老板问我为什么用户流失率突然升高，我只能说'可能是XX'，但没有依据"
   - 影响：无法提供决策支持

## 需求列表
1. 数据自动汇总功能（明确需求）
   - 来源：用户明确提出"希望能一键拉取所有平台数据"
   - 价值：节省1小时/周

2. 数据异常归因分析（隐含需求）
   - 来源：用户多次提到"不知道原因"、"只能猜测"
   - 价值：提升决策质量
```

---

**第2步：AI按KANO模型分类需求（10分钟）**

把第1步提取的需求列表，让AI按KANO模型分类。

**Prompt模板：**

```
以下是我提取的需求列表：

【粘贴需求列表】

请按KANO模型对这些需求进行分类：

- **基本型需求**：用户认为理所当然的，没有会很不满
- **期望型需求**：用户明确期望的，有了会满意
- **兴奋型需求**：用户没想到的，有了会惊喜
- **无差异需求**：做了也不会提升满意度
- **反向需求**：做了反而会降低满意度

对每个需求，说明：
1. 属于哪个类型
2. 为什么这样分类
3. 实现成本估计（高/中/低）
4. 建议优先级（P0/P1/P2）

输出格式：
## 基本型需求
1. 【需求名称】
   - 分类理由：...
   - 实现成本：...
   - 优先级：...
```

---

**第3步：AI结合业务数据智能排序（10分钟）**

把分类好的需求，结合业务目标和资源约束，让AI排优先级。

**Prompt模板：**

```
以下是按KANO模型分类的需求列表：

【粘贴分类后的需求】

请结合以下业务背景，给出需求的优先级排序：

**业务目标**：
- Q3的核心目标是提升用户留存率10%
- 开发资源有限，只能做3个需求

**约束条件**：
- 开发周期：每个需求平均2周
- 技术债：有2个历史遗留问题需要修复

请给出：
1. 推荐的需求排序（Top 3）
2. 每个需求的理由（为什么优先做这个）
3. 不推荐的需求及原因
4. 风险提示（如果不做某个需求会有什么风险）

输出格式：
## 推荐排序
### P0：【需求名称】
- 推荐理由：...
- 预期价值：...
- 风险：...
```

---

**完整工作流耗时：30分钟（10分钟×3步）**

**以前手动做：2天**

**效率提升：约10倍**

## 工作流2：竞品分析——从快速调研到深度拆解

### 场景

老板让你做一份竞品分析报告，deadline是3天后。

以前要花3天时间上网找资料、试用产品、写报告，现在用AI工作流只要3小时。

### 工具推荐

- • **信息搜集** ：Perplexity AI（联网搜索+总结能力强）
- • **产品拆解** ：Claude + 截图分析
- • **报告生成** ：Notion AI / 飞书AI

### SOP流程

**第1步：AI快速调研（30分钟）**

让AI帮你快速搜集竞品的基本信息、市场定位、用户评价。

**Prompt模板：**

```
我需要做【产品名称】的竞品分析，请帮我搜集以下信息：

1. 产品基本信息
   - 公司背景、成立时间、融资情况
   - 产品定位、目标用户
   - 核心功能、商业模式

2. 市场表现
   - 用户规模、增长趋势
   - 市场份额、行业排名
   - 最新动态（近3个月）

3. 用户评价
   - App Store / Google Play 评分
   - 用户好评、差评的核心内容
   - 高频提及的功能

4. 竞争优势
   - 和其他竞品相比，有什么独特之处
   - 用户为什么选择它

请从公开资料中搜集信息，给出信息来源链接。
```

---

**第2步：AI深度拆解（1小时）**

把竞品的核心功能截图，让AI帮你拆解设计逻辑和产品策略。

**Prompt模板：**

```
我上传了【竞品名称】的产品截图，请帮我分析：

1. 页面结构
   - 信息架构是什么逻辑
   - 为什么这样设计

2. 交互设计
   - 核心操作路径是什么
   - 有哪些巧妙的设计细节

3. 产品策略
   - 这个功能解决的是什么问题
   - 目标用户是谁
   - 为什么用这种方式解决

4. 可借鉴之处
   - 哪些设计值得我们学习
   - 如果我们要做类似功能，可以怎么优化

【上传截图】
```

---

**第3步：AI生成竞品分析报告（1.5小时）**

把前两步的信息，让AI帮你生成一份结构化的竞品分析报告。

**Prompt模板：**

```
我需要写一份竞品分析报告，以下是我搜集的信息：

【粘贴第1步和第2步的输出】

请帮我生成一份结构化的报告，包含以下内容：

## 1. 竞品概述
- 产品定位
- 目标用户
- 核心功能

## 2. 竞品优势分析
- 功能优势（和我们相比）
- 体验优势
- 运营优势

## 3. 竞品劣势分析
- 功能短板
- 用户痛点（从差评中提取）

## 4. 策略建议
- 我们可以借鉴的地方（Top 3）
- 我们可以做差异化的地方（Top 3）
- 具体行动建议

报告要求：
- 数据要有来源
- 结论要有依据
- 建议要可执行
```

---

**完整工作流耗时：3小时**

**以前手动做：3天**

**效率提升：约8倍**

## 工作流3：PRD撰写——从需求结构化到评审准备

### 场景

你要写一份PRD，包括需求背景、功能说明、用例设计、评审材料。

以前要2天，现在用AI工作流只要2小时。

### 工具推荐

- • **需求结构化** ：Claude / ChatGPT
- • **用例生成** ：自定义GPTs
- • **文档撰写** ：Notion AI / 飞书AI

### SOP流程

**第1步：AI结构化需求（30分钟）**

把你脑子里的需求想法，让AI帮你整理成结构化的需求说明。

**Prompt模板：**

```
我要做一个功能，以下是我的想法：

【描述你的需求想法】

请帮我把这个需求结构化，按以下格式输出：

## 1. 需求背景
- 业务目标：为什么要做这个功能
- 用户痛点：解决用户什么问题
- 预期价值：做了之后能带来什么价值

## 2. 目标用户
- 核心用户：谁会用这个功能
- 使用场景：在什么情况下会用
- 使用频率：多久用一次

## 3. 功能说明
- 核心功能：最核心的能力是什么
- 辅助功能：配套需要的功能
- 不做的功能：明确边界

## 4. 成功指标
- 核心指标：如何衡量成功
- 目标值：期望达到多少

帮我补充我没想到的部分，并指出逻辑漏洞。
```

---

**第2步：AI生成用例（30分钟）**

让AI帮你生成正常用例、异常用例、边界用例。

**Prompt模板：**

```
以下是我的需求说明：

【粘贴第1步的需求说明】

请帮我生成完整的用例，包括：

## 1. 正常用例
- 用例编号、用例名称
- 前置条件
- 操作步骤
- 预期结果

## 2. 异常用例
- 用户操作错误的情况
- 系统异常的情况
- 边界条件

## 3. 性能要求
- 响应时间
- 并发量
- 数据量

## 4. 开发关注点
- 技术难点
- 依赖项
- 风险点

用例格式：
| 用例编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|---------|---------|---------|---------|---------|
```

---

**第3步：AI准备评审材料（1小时）**

让AI帮你准备需求评审会的PPT大纲和答辩问题。

**Prompt模板：**

```
我要在需求评审会上讲这个需求，参会人有产品总监、开发leader、设计师。

需求内容：
【粘贴需求说明】

请帮我：

1. 生成评审PPT大纲（5-8页）
   - 每一页的标题和核心内容
   - 重点要讲清楚的地方

2. 预测可能被问到的问题（Top 10）
   - 产品总监可能问什么
   - 开发leader可能问什么
   - 设计师可能问什么

3. 准备每个问题的回答要点

PPT大纲格式：
## 第1页：需求背景
- 核心内容：...
- 讲解要点：...
```

---

**完整工作流耗时：2小时**

**以前手动做：2天**

**效率提升：约8倍**

## 工作流4：数据分析——从指标诊断到策略推荐

### 场景

你的产品某个核心指标下降了，老板让你找原因并给出解决方案。

以前要1天分析数据+半天写报告，现在用AI工作流只要2小时。

### 工具推荐

- • **数据诊断** ：Claude / ChatGPT（可以分析CSV数据）
- • **可视化** ：Code Interpreter（可以生成图表）
- • **策略推荐** ：自定义GPTs

### SOP流程

**第1步：AI快速诊断（30分钟）**

把数据导出成CSV，让AI帮你快速找到异常点。

**Prompt模板：**

```
我上传了过去30天的用户行为数据（CSV格式），核心指标是【指标名称】，最近7天下降了15%。

请帮我：

1. 分析数据趋势
   - 哪一天开始下降的
   - 下降的幅度和速度

2. 诊断可能原因
   - 从数据中找异常点（用户分群、行为路径、时间分布）
   - 列出3-5个可能的原因

3. 验证假设
   - 如何验证每个原因
   - 需要看哪些补充数据

【上传CSV文件】
```

---

**第2步：AI用户分群分析（30分钟）**

让AI帮你做用户分群，找到核心问题用户。

**Prompt模板：**

```
基于上传的数据，请帮我做用户分群分析：

1. 按行为特征分群
   - 活跃用户 vs 流失用户
   - 高价值用户 vs 低价值用户

2. 找出问题用户群
   - 哪一群用户的指标下降最明显
   - 这群用户有什么共同特征

3. 对比分析
   - 问题用户群 vs 正常用户群的行为差异
   - 可能的原因是什么

输出格式：
## 用户分群结果
| 用户群 | 人数 | 指标变化 | 核心特征 |
|-------|-----|---------|---------|

## 问题诊断
- 核心问题：...
- 影响范围：...
- 可能原因：...
```

---

**第3步：AI生成策略推荐（1小时）**

让AI基于分析结果，给出可执行的优化策略。

**Prompt模板：**

```
基于前面的数据分析，请给出优化策略：

分析结论：
【粘贴前两步的分析结果】

请给出：

1. 短期应急措施（1周内可以做的）
   - 具体动作
   - 预期效果
   - 风险提示

2. 中期优化方案（1个月内）
   - 功能优化方向
   - 运营策略调整
   - 资源需求

3. 长期改进建议（3个月）
   - 产品战略调整
   - 能力建设

4. 验证指标
   - 如何衡量优化效果
   - 观测周期

输出格式：
## 策略矩阵
| 时间 | 策略 | 预期效果 | 资源需求 | 风险 |
|-----|-----|---------|---------|------|
```

---

**完整工作流耗时：2小时**

**以前手动做：1.5天**

**效率提升：约6倍**

## 工作流5：项目管理——从风险识别到复盘总结

### 场景

你负责一个跨部门项目，要做风险管理、进度跟踪、最后写复盘报告。

以前每周要花半天时间开会+整理，现在用AI工作流只要1小时。

### 工具推荐

- • **风险识别** ：Claude / ChatGPT
- • **会议纪要** ：飞书妙记 / Otter.ai
- • **复盘总结** ：Notion AI

### SOP流程

**第1步：AI项目风险识别（20分钟）**

项目启动时，让AI帮你识别潜在风险。

**Prompt模板：**

```
我负责一个项目，以下是项目信息：

**项目目标**：【描述目标】
**参与部门**：【列出部门】
**时间节点**：【列出关键节点】
```

## 如何建立自己的AI工作流？3个核心原则

看完这8个工作流，你可能会问： **我怎么建立自己的AI工作流？**

我总结了3个核心原则：

### 原则1：标准化——把重复性工作变成固定流程

**识别哪些工作是重复的：**

- • 每周/每月都要做的事
- • 步骤固定的工作
- • 可以套模板的工作

**设计标准化流程：**

```
输入 → AI处理 → 输出 → 人工优化
```

举个例子：

需求分析这个工作，每次都是：

1. 1\. 收集用户反馈
2. 2\. 提炼需求
3. 3\. 排优先级

这就是一个可以标准化的流程。

你可以设计一套固定的Prompt模板，每次直接套用。

---

### 原则2：自动化——让AI处理80%的基础工作

**哪些工作可以让AI自动化：**

- • 信息搜集（搜索、整理）
- • 内容生成（文档、报告）
- • 数据分析（趋势、异常）
- • 格式转换（结构化、可视化）

**你要做的是剩下20%的高价值工作：**

- • 判断方向
- • 做决策
- • 创意思考
- • 人际沟通

**记住一个公式：**

> “
> 
> **你的价值 = AI处理的基础工作量 × 你的判断质量**

AI帮你处理80%的基础工作，你把省下来的时间用来提升判断质量——这才是AI时代的正确打开方式。

---

### 原则3：可复用——把一次性Prompt变成工作流模板

**大部分人用AI的问题：**

- • 每次都是临时想一个Prompt
- • 用完就忘，下次又要重新想
- • 没有积累，效率提升不明显

**正确做法：**

- • 把好用的Prompt整理成模板
- • 按工作场景分类（需求分析、竞品分析、数据分析等）
- • 持续优化和迭代

**我的建议：**

建一个"AI工作流模板库"（用Notion/飞书/Obsidian都行）：

```
📁 需求分析
  ├─ 用户访谈分析.md
  ├─ 需求优先级排序.md
  └─ 需求评审准备.md

📁 竞品分析
  ├─ 快速调研.md
  ├─ 深度拆解.md
  └─ 策略建议.md

📁 数据分析
  ├─ 指标诊断.md
  ├─ 用户分群.md
  └─ 策略推荐.md
```

每个文档里存：

- • 场景说明
- • Prompt模板
- • 使用示例
- • 注意事项

**这样做的好处：**

- • 下次遇到同样工作，直接用模板
- • 可以持续优化模板
- • 新人来了可以直接复用
